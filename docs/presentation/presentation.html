The problem

One sentence from a creator.
The brand carries the liability.

  • Prescription skincare is regulated advertising. German health-advertising law limits what may be claimed about a treatment.
  • Creators don't speak in legal language. Ordinary influencer phrasing is often a promise of certain success.
  • Manual review doesn't scale. Every video, every language, line by line — before launch.

The techniques

Six applied-AI methods, each solving a specific failure

Retrieval

RAG over two corpora

The model reasons from retrieved statute text, not training memory — so a strategist can verify the verdict.

Representation

Embeddings + semantic search

1536-d vectors, cosine similarity, top-8 with a relevance floor so weak matches are refused, not guessed at.

Orchestration

Tool-calling agent

Function calling routes each question to the right tool and holds conversation memory across turns.

Reliability

Structured outputs

The verdict is enum-constrained to a 4-level scale. The model cannot return a value outside it.

Evaluation

LLM-as-judge + holdout

Automated faithfulness and correctness scoring, measured against hand-labelled sets and an unseen holdout.

Safety

Adversarial testing

18 red-team cases against the live agent — the only way to find what accuracy metrics structurally cannot.

Retrieval is the bottleneck — not generation. Knowing which half is weak is what turns "improve the AI" into an actual work item.

We also audited our own model comparison and retracted half of it: once sampling was controlled, half the 24-point gap turned out to be single-run noise.
